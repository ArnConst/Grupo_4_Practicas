# 🛠️ TechSolve 🛠️
---------------------------------------------------------------------
**TechSolve** es una plataforma interna de gestión y seguimiento de incidencias (tickets de soporte técnico) diseñada para optimizar la comunicación entre los empleados de la organización y el equipo de soporte técnico.

-------------------------------------------------------------------

## ⚙️ Novedades y Últimas Actualizaciones

 **Visualización Dinámica de Tickets ("Mis Tickets"):**
 - Implementación de una tabla interactiva para listar y dar seguimiento a los tickets creados.
  - Se agregó JS para que la información se cargue y actualice sola en la pantalla, al instante y sin tener que recargar la página

**Sistema de Control de Acceso por Roles (RBAC):**
  - Segmentación de vistas y permisos según el tipo de usuario (Empleado vs. Técnico).

**Panel Exclusivo para Técnicos:**
  - Nueva interfaz dedicada donde los técnicos pueden visualizar, filtrar y gestionar los tickets asignados y pendientes.
  
  **Gestión de Cuentas y Credenciales:**
  - Habilitación de cuentas individuales con credenciales seguras para cada empleado.
  - Registro y seguimiento autónomo e independiente de tickets por usuario.
